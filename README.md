**The first mod in 1.12.2 (or even Minecraft ?) that creates real and meaningful paths and bridges through the world ! (only for Millénaire villages for now)**

The mod is still in very early development so don't use it in "prod" instances or backup your worlds before using it
I strongly recommend using RTG since I built my mod using RTG world generation (it's just configured for it)

It's a complex pathfinder that will try to find the best paths between villages and lonebuildings. You'll be able to travel using these paths
